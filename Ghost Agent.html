How it works

Five things happen between pasting a note and reading the answer.

  1. 1

    Underline

    Ghost Agent checks the field 300 ms after your last keystroke, or at once on paste. Each sensitive value gets a wavy underline in the colour of its Category. The site's own editor is never changed.

    fnr 01019000083, Kari har diabetes

    IDs, cards, secrets Names and contact data Domain words and your own words
  2. 2

    Open the Card

    Hover an underlined value and a Card opens above it. It names the Category, shows the Placeholder that would replace the value, and offers three choices: Hide, Rephrase or Ignore.

    Phone number
    +47 912 34 567hide as [PHONE_1]
    Hide Rephrase Ignore
  3. 3

    Hide

    Hide swaps one value for a typed, numbered Placeholder. The same value always gets the same Placeholder, so the AI can tell two people apart. Hide all does the whole field in one step.

    fnr 01019000083→fnr [FNR_1]
    6 to check
  4. 4

    Rephrase

    Rephrase rewrites the whole sentence into a more general one, using a small language model that runs on your computer. You read the new sentence first and choose Accept or Reject.

    Kari, 34 år, jobber som lærer i Bærum og har diabetes type 1.

    New sentence

    En kvinne i 30-årene som jobber i skolen, har en kronisk sykdom.

    AcceptReject
  5. 5

    Read the answer

    The AI answers with the same Placeholders, such as [PERSON_1], so its answer keeps the structure of your text. The originals wait in the Vault, which lives in memory for this tab only.

    The AI's answer

    Jeg henviser [PERSON_1], som har [HEALTH_1].

Ghost Agent never sends your text anywhere.

Ghost Agent exists to keep sensitive data away from third-party services, so it must not send that data anywhere itself. This is a hard rule, even where a cloud model would be better or faster.

  • Detection and Rephrase both run on your computer.
  • No cloud APIs and no usage tracking.
  • No logging of your text, not even debug logs.
  • The Engine listens on 127.0.0.1 only.
  • The Vault lives in memory and is cleared when the browser closes.

What it finds

Each Finding comes from a Detector on your computer. Numbers must pass their checksum, so an order number like ordrenummer 01019000084 is left alone.

The Health row belongs to the Health Domain. In the Free Domain, which is the default, only the Base Categories above it are found.

On top of these rules, the GLiNER Detector, a small language model running on your computer, finds surnames, places and addresses that no list or checksum can catch.

Tune it from the toolbar

Click the ghost in the browser toolbar to choose where Ghost Agent runs and what it looks for. Nothing here leaves the extension.

  • A switch per siteTurn Ghost Agent off on a site you trust, and back on with one click.
  • DomainsChoose from five Domains. Free finds the Base Categories, and Health adds diagnoses and medicines. Make your own with the plus button.
  • Your own wordsAdd client names, project code names or places the Detectors can't know. They get a teal underline, like Domain words.
  • Engine statusIf the local Engine isn't running, the icon shows a red ! and the popup tells you how to start it.

Why not just…?

There are other ways to keep personal data out of an AI chat. Each one gives up something Ghost Agent keeps.

…tell people to be careful?

A busy nurse pastes the whole note in one go. Nothing on screen points at the fødselsnummer in line two. Ghost Agent does, the moment the text lands in the field.

…ban AI chat at work?

People who find AI useful keep using it, on a phone or at home, where nobody can help them. Ghost Agent lets them keep the tool and drop the data.

…send the text to a redaction service?

Then the patient note goes to one more third party before it is cleaned. Ghost Agent's Detectors and language model run on your own computer.

…buy an enterprise AI plan?

It changes who keeps the data, not whether it leaves. The AI provider still receives the real name and fødselsnummer. With Ghost Agent it receives [PERSON_1] and [FNR_1].

Run it yourself

Ghost Agent has two parts: a local Engine and a browser extension. Start the Engine, load the extension, and open ChatGPT.

  1. 1

    Get the code

    git clone https://github.com/dimassolt/marka_mvp_2.git
    Open the repository
  2. 2

    Start the Engine

    You need Python and uv. The Engine loads its models once at start, then waits on your machine only.

    cd engine && uv run ghost-engine

    It is ready when http://127.0.0.1:8765/health answers {"status": "ok"}.

  3. 3

    Load the extension

    Build it as the README describes. Then open opera://extensions or chrome://extensions, turn on Developer mode, choose Load unpacked and pick the built folder.

  4. 4

    Try it

    Open chatgpt.com and paste the demo note. The sensitive values get underlined almost at once.

What you need

  • EnginePython with uv
  • BrowserAny Chromium browser
  • SitesAny site. Plain textarea fields are not scanned yet.
  • NetworkNone at run time. The Engine listens on 127.0.0.1:8765 only.

If the toolbar icon shows a red !, the Engine isn't running. Start it and the underlines come back.

Processing stays local

Cloud APIs, tracking and logging of user text are ruled out, even for debugging.

Thin extension, local engine

One Engine core serves the extension now and a desktop App later, with no detection logic duplicated.

Typed, numbered Placeholders
